# 爆款标题 A/B 生成

> 篝火出品 · 收录于篝火 App 应用区

按平台风格批量出标题并打分

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/title-ab-generator/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `title-ab-generator_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `title-ab-generator_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `title-ab-generator_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

填一个选题、选几个平台，批量出候选标题并由大模型打分；也可以贴两组自己写的标题，比较哪组更好。

**批量出标题**

1. 第一次使用先到「设置」页填自己的大模型接口地址、密钥和模型名（兼容 OpenAI 接口格式），密钥只保存在本机。
2. 在「选题」框里一行写一个选题（最多 10 个），也可以点「从 txt 导入」或把 txt 文件拖进窗口。
3. 选平台风格：公众号、小红书、抖音、视频号、B 站，可多选。「每个平台出几个」默认 6 个，范围 3 到 20。
4. 「字数上限」填 0 时只检查公众号（32 字，依据微信开发者文档「新增草稿」接口），其他平台上限未核实，需要时自己填。「补充要求」可写目标人群或关键词。
5. 点「生成并打分」。每个「选题 × 平台」先生成一次，再按每 15 个一批打分，界面会预估调用次数，生成中可以随时停止。
6. 结果是一张张标题卡片：左边大字是综合分，右边是字数、吸引力、清晰度、合规风险三条评分条和理由；每组里综合分最高的标「最佳」，风险点用橙色单独标出。点卡片右上角可复制标题。综合分 = 吸引力 × 40% + 清晰度 × 30% + (10 − 合规风险) × 30%。
7. 点「导出 Excel」保存到「下载/爆款标题 A／B 生成」文件夹（也可点「选择保存位置」改位置）。

**A／B 对比**

1. 切到「A／B 对比」，两个框里分别贴 A 组和 B 组标题，每组最多 30 个；也可以导入 txt，用单独一行「A组」「B组」分组，或用一行 `---` 隔开两组。
2. 选按哪个平台评判，内容主题可不填（写上打分更准）。
3. 点「打分并对比」。两组放在同一次调用里打分，尺度一致，通常只调用 1 次。
4. 结果页顶部是两组的大号平均分，较好的一组标「更好」，下面有一段文字点评和两组的逐条评分；可导出 Excel。

打开时显示的是标明「示例」的结果，用来预览界面，不是真实打分。分数和风险提示由大模型给出，仅供参考，不构成法律意见。

## 验收用例

| 操作 | 应得到 |
|---|---|
| 打开工具，不做任何操作 | 候选标题区显示带「示例」标记的 12 个标题卡片，每张卡片有综合分、三条评分条、理由 |
| 设置页不填接口，直接点「生成并打分」 | 提示「还没有设置大模型：请到「设置」里填写接口地址、密钥和模型名」，界面不崩溃 |
| 设置页填好接口，点「从 txt 导入」选 `samples/选题示例.txt` | 选题框出现 3 行，提示「导入 3 个选题」 |
| 平台选公众号、小红书，每个平台出 6 个，点「生成并打分」 | 等待结束后出结果，提示「生成 12 个标题，调用大模型 N 次」；每个「选题 × 平台」各有一张标「最佳」的卡片；公众号标题超过 32 字的显示红色「超过 32 字」 |
| 点平台标签「小红书」 | 只显示小红书的标题，按综合分从高到低排列 |
| 切到「A／B 对比」，导入 `samples/两组标题示例.txt` | A 组 3 个、B 组 3 个，提示「导入 A 组 3 个、B 组 3 个标题」 |
| 点「打分并对比」 | 两组各显示平均综合分，较好的一组有「更好」标记；下方有文字点评和两组逐条评分；提示「对比完成，调用大模型 1 次」 |
| 点「导出 Excel」 | 批量页生成 `候选标题-日期-时分.xlsx`，对比页生成 `标题AB对比-日期-时分.xlsx`；表头与界面一致（批量表为「排名、平台、选题、标题、字数、吸引力……字数提示」），高风险和超字数的单元格标红 |
| 导入只有一组标题、没有分组的 txt（在对比页） | 提示「只找到一组标题：请用单独一行「A组」「B组」分组，或用一行 --- 隔开两组」 |

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
